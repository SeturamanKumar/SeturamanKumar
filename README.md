Full-stack developer with experience in frontend and backend. Currently focusing on DevOps and cloud infrastructure.

### 📁 Projects

**SquadHost — Minecraft Server Hosting Platform**  
Next.js, Python/Django, PostgreSQL, Docker, AWS, Terraform, Ansible
- Built a cloud-based platform to launch and manage Minecraft servers on AWS (alternative to paid services like Aternos)
- Users access a web interface to select server specs and launch servers on demand
- Minecraft servers auto-shutdown after 8 minutes of no players to save costs
- Master server monitors for active Minecraft instances; if none running for 10 minutes, it backs up the PostgreSQL database and world files to S3, then terminates itself to achieve scale-to-zero billing
- Infrastructure (VPC, subnets, RDS, EC2, Lambda, IAM) created using Terraform; server setup automated with Ansible

**Portfolio Website — seturaman.me**  
Next.js, Node.js/Express, AWS (Lambda, API Gateway, SES, CloudFront)
- Static site hosted on CloudFront
- Contact form sends emails using serverless Lambda function

**Mini PCs Homelab (Planning)**
